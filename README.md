# AI 8 Puzzle Game (Android)

An Android implementation of the classic **8 Puzzle Game** enhanced with an **AI solver** that calculates optimal moves in real time.

## Features

- Sliding tile puzzle gameplay
- Swipe gesture tile movement
- Multiple goal modes:
  - Standard Goal
  - Spiral Goal
  - Reverse Goal
- Optimal solution calculation using **A\* algorithm**
- Native C++ solver via **JNI**
- Performance comparison:
  - Player Moves
  - Optimal Moves
  - Minimum Remaining
- Animated splash screen
- Modern UI with glassmorphism design

## Tech Stack

- Kotlin
- Android SDK
- ConstraintLayout
- RecyclerView
- Coroutines
- JNI
- C++ (Native Solver)
